# Seguridad

No publicar credenciales, tokens, cookies, CUIT reales, comprobantes, exportaciones ni perfiles de clientes en issues, pull requests, pruebas o ejemplos.

Para informar una vulnerabilidad, usar un aviso privado de seguridad del repositorio. No incluir datos productivos en la reproducción; reemplazarlos por valores ficticios determinísticos.

Las escrituras contra SOS Contador deben conservar el flujo de previsualización, confirmación explícita y verificación independiente definido por la skill.
